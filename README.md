# HTML Slide Starter

ブラウザで開くだけで動く、16:9プレゼン用HTMLスライドの出発点です。

---

## ディレクトリ構成

```
slide-starter/
├── CLAUDE.md              ← AI向け仕様書
├── design-guidelines.md   ← デザイン方針
├── plan.md                ← 構築ガイド
├── engine/
│   ├── slide.css          ← 16:9ロック・ナビUI・PDF出力（触らない）
│   └── slide.js           ← キーボード操作・スケーリング・PDF（触らない）
├── theme/
│   └── sample.css           ← デザイントークン（カスタマイズはここだけ）
├── shared/                ← 共有アセット（ロゴ・テクスチャ等）
└── decks/
    └── 01_sample/
        └── index.html     ← サンプルデッキ
```

**3層分離の設計思想：**
- `engine/` ── どんなデッキでも共通のロジック。更新したら全デッキに反映される
- `theme/` ── カラー・フォント・余白の変数。テーマ変更はここだけ触る
- `decks/{name}/index.html` ── 発表ごとのコンテンツ。デザインには干渉しない

---

## 使い方

### 1. まず動かす
`decks/01_sample/index.html` をブラウザで開く → 矢印キーでスライドが切り替わる。

### 2. 新しいデッキを作る
`decks/` にフォルダを作り、`01_sample/index.html` をコピーして編集する。

```
decks/
├── 01_sample/index.html
└── 02_my-talk/index.html   ← 新しいデッキ
```

### 3. スライドを追加・編集する

```html
<section class="slide slide-content">
  <div class="body">
    <h2>新しいセクション</h2>
    <p>内容をここに書く。</p>
  </div>
</section>
```

### 4. テーマをカスタマイズする
`theme/sample.css` の `:root` 変数を変えるだけ。

```css
--color-accent:  #f472b6;   /* ピンクに変更 */
--color-bg:      #0a0a0a;   /* より深い黒に */
```

### 5. PDFに書き出す
- UIの **PDF** ボタンをクリック
- または Ctrl + P → 「背景のグラフィック」ON・余白なし で印刷

### 6. Vercelにデプロイする
```bash
vercel
```
数秒でURLが発行される。「スライドを送る」ではなく「リンクを送る」体験へ。

## キーボードショートカット

| キー | 操作 |
|------|------|
| → / ↓ / Space | 次のスライド |
| ← / ↑ | 前のスライド |
| F | フルスクリーン切替 |

---

## スライドタイプ一覧

| クラス | 用途 |
|--------|------|
| `slide-title` | タイトルスライド（最初の1枚） |
| `slide-content` | 汎用コンテンツ（本文・箇条書き・カード・図解） |
| `slide-section` | セクション区切り（章立て） |
| `slide-landing` | 核心の一文を大きく見せる全画面スライド |
| `slide-end` | エンディング |

## 図解コンポーネント

| パターン | クラス | 用途 |
|----------|--------|------|
| フローチャート | `flow` + `flow-step` + `flow-arrow` | プロセス・手順 |
| カードグリッド | `cols-3` + `card` | 並列の概念・3つの柱 |
| 数字ハイライト | `cols-3` + `stat` | KPI・成果指標 |
| 2カラム比較 | `cols-2` | Before/After |

## ユーティリティクラス

| クラス | 効果 |
|--------|------|
| `accent` | アクセント色でテキストを表示 |
| `muted` | 薄いグレーでサブ情報を表示 |
| `mono` | モノスペースフォントに切替 |
| `bold` | 太字 |
| `divider` | 水平線 |
| `cols-2` | 2カラムグリッド |
| `cols-3` | 3カラムグリッド |
| `list` | アクセント付き箇条書き |
| `card` | ボーダー付きカードボックス |
| `tag` | モノスペースのタグバッジ |
