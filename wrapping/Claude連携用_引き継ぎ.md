# Chammi オリジナル包装紙デザイン — Claude連携用引き継ぎ

## 目的
Chammiの忘年会（2026-11-25）景品「高知の人気6点ギフトセット」を包む、Chammiデザインのオリジナル包装紙を作る。デザインはClaude側で仕上げ・調整し、印刷入稿データまで作りたい。

## デザインの方向性（確定済み）
- Chammiピッチ資料の表紙の総柄を再現する：淡ピンク地に線画モチーフの散らし柄＋「CHAMMI」ワードマーク
- 案は2つ：A案＝ロゴ黒（表紙どおり）、B案＝ロゴもピンク（同系色で上品）
- 継ぎ目のないシームレスな繰り返しパターン（タイル）にする

## カラー
- 地色: #FAE2E5（淡ピンク）
- モチーフ線: #E7ABB8（少し濃いピンク、細い線画）
- A案ロゴ: #232021（ほぼ黒）
- B案ロゴ: #D88294（ミディアムピンク）

## モチーフ（線画アウトライン）
ハート / 四つ星スパークル / 星 / 王冠 / 花 / 吹き出し / リボン / カチンコ / 口紅
（元ネタはピッチ資料表紙 `cover-01.png` を参照）

## ワードマーク
- 「CHAMMI」全大文字、丸みのある太字サンセリフ
- 添付タイルでは Comfortaa Bold で代用。本物のロゴデータがあればそちらに差し替え

## 同梱ファイル
- `tile_a.png` / `tile_b.png`：シームレス・タイル（1200×1200px）。これを繰り返せば任意サイズの紙面になる
- `sheet_a.jpg` / `sheet_b.jpg`：タイルを並べた全体プレビュー
- `cover-01.png`：ピッチ資料表紙（デザインの元ネタ）
- `make_pattern.py`：タイル生成スクリプト（PIL）。モチーフ配置・密度・色はここで調整可能

## 印刷仕様（発注先候補：アイリィデザイン）
- サイズ：四六判 788×545mm
- 25枚 ¥4,160〜、最短2営業日出荷
- 入稿データは実寸300dpi（約9300×6430px）相当が目安。タイルを実寸で繰り返して全面データ化する

## Claudeへの依頼例（コピペ用プロンプト）
---
添付のタイル画像（シームレスパターン）と引き継ぎメモをもとに、Chammiのオリジナル包装紙デザインを仕上げてください。

やってほしいこと：
1. モチーフの配置をもう少しランダムに散らして、格子感をなくす（密度は現状程度）
2. A案（ロゴ黒）とB案（ロゴピンク）の両方を、四六判788×545mm・300dpiの印刷入稿データ（PDFまたはPNG）に展開する
3. 同じ柄でメッセージカード（100×148mm）のデザインも作る。表面は柄＋CHAMMIロゴ、裏面は白地に罫線
4. 実際の紙に包んだイメージのモックアップも見せてほしい

色・モチーフ・フォントの指定は引き継ぎメモのとおり。変更案があれば理由つきで提案して。
