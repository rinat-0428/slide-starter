# Chammi オリジナル包装紙（2026忘年会 景品用）

`python3 make_wrapping.py` で `out/` 以下をすべて生成し直せます（約30秒）。モチーフ・密度・色・シードはスクリプト冒頭の定数と `layout()` の引数で変えられます。

## 出力（out/）
| ファイル | 内容 |
|---|---|
| `print_{A,B}_shiroku_788x545mm_bleed3mm.pdf` / `_300dpi.png` | 四六判の入稿データ。塗り足し3mm込み（794×551mm、9377×6507px） |
| `tile_{a,b}_200mm_300dpi.png` | シームレスタイル（200mm角） |
| `card_{A,B}_100x148mm_bleed3mm.pdf` | メッセージカード（1ページ目 表、2ページ目 裏）。PNGも同梱 |
| `mockup_{a,b}.jpg` | 包装イメージ |
| `preview_sheet_{a,b}.jpg` | 全体プレビュー |

## 引き継ぎメモからの変更点
- 配置：格子にジッターを加える方式をやめて、Poisson-disk配置に変更。格子感がなくなり、入稿データ全面を直接生成しているので繰り返しの継ぎ目も出ません
- ロゴ書体：Comfortaa から Montserrat ExtraBold に変更。実際のCHAMMIロゴ（ピッチ資料の表紙）の太い幾何学サンセリフに近く、Comfortaaは細すぎて別物に見えたため。本物のロゴデータがあれば `wordmark()` を差し替えてください
- モチーフ：表紙にある「フィルム」と「ペンライト」（推し活のモチーフ）を追加。口紅は頻度を下げて残しています
- カード表面に小さく「THANK YOU 2026」、裏面に TO / FROM を入れました（不要なら `card()` から削除してください）

## キャラクター
- `chars/char1_front.png`：キャラ設定画の正面図を切り抜いたもの（カラー）
- `chars/char1_front_pink.png`：包装紙用のピンク・モノトーン版
- 包装紙にはピンク版を高さ58mmで散らし、カード表面にはカラー版を高さ96mmで配置
- 2体目を追加するときは `chars/{name}_front.png` と `_front_pink.png` を置いて `CHAR_NAMES` に名前を足す

## 入稿時の注意
- データはRGBです。印刷会社側でCMYKに変換されると、淡いピンクが少しくすむ可能性があります
- 塗り足しの要否と寸法は、発注先のテンプレートで確認してください
