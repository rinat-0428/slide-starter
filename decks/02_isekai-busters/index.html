切り抜き要素——全8シーン

EP.#13–16 / ELEVATOR エレベーター儀式——ボタンを押す手

震える手でボタンを押す実咲季。閉じる寸前に扉を阻む白い手。背後に長い黒髪の女。「1階を押したのに表示が上昇していく」——

「実際やってみた」系ショート展開可能。日本中のエレベーターが怖くなる。
EP.#23–25 / KUCHISAKE-ONNA 口裂け女のマスク剥ぎ

「マスクとって話してくれますか」——外れた顔に裂けた口。包丁を振り上げ突進。今田の頬をかすめた包丁が木に刺さる。

「AIで再現された口裂け女」がそのままバズワードに。最大の視覚的インパクト。
EP.#26–28 / TEKE-TEKE テケテケが野上を食い殺す

腹の裂けた女子高生が這いながら迫り、野上の鼻を食いちぎる。AIの3D風表現でリアルとアンリアルの境界を攻める。

「AIでここまで描けるのか」という驚き。視覚的インパクト×グロテスク。
EP.#19–22 / LOOP OBĀCHAN 二つの家から同じ老婆が出てくる

インターホンを押すと老婆が無言で見つめる。向かいの家を訪ねると——また同じ老婆。そして異常なスピードで追いかけてくる。

「ゆっくりした恐怖→爆発的な追跡」の緩急がショートに最適。
EP.#37–40 / MARY-SAN メリーさんの着信連鎖

圏外のスマホに突然着信。「いま、がっこうのまえ」→「いま、こうしゃのなか」→「いま……うしろ」。今田が振り返り、首が一回転。

テキスト演出が縦型ショートと完全一致。「絶対に振り返ってはいけない」が視聴者を能動参加させる。
EP.#29 / JINMENKEN 人面犬の出現

血だらけの野上の死体の傍に、犬コスプレの男が四つん這いで現れ「わんっ！」。一同が将棋倒しになって尻もちをつく。

「怖い×笑える」が混在する唯一のシーン。コメント欄が荒れる系の爆発力あり。
EP.#32 / HANAKO-SAN 花子さんの召喚シーン

三番目の扉を三回ノック「はーなーこさん」。電気が明滅し、三人の背後に突然、赤い吊りスカートの美形少女が立っている。

「実際に学校のトイレで試せる」都市伝説性。ビジュアルショックがショートに最適。
EP.#64–66 / FINAL RESOLVE 実咲季と綺星の最後の覚悟

「元のつらい世界に戻りたくなかった」「正直あたしも、心から戻りたいって世界じゃないし」——手を繋ぎ、スコップを振り上げ走り出す。

逃げ場のない現実と異世界の地獄が同等になる瞬間。「逃げることをやめた二人」が視聴者の共感を爆発させる。
